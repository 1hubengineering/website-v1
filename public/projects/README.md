# Project graphics

Graphics were copied from the supplied project sources on 2026-11-09. They are
served locally so the portfolio does not depend on third-party image requests.
The image files are unchanged; the site fits each whole image inside its preview.

## Linux Setup

Source: [Terminal preview gallery](https://github.com/1hubengineering/linux-setup/blob/main/docs/previews.md).
Original files: `docs/assets/{quick-term,custom-themes,iterm2,command-picker,skill-manager}.png`.

Quick-term, iTerm2, and the custom-theme gallery are rendered examples of actual
Oh My Posh configurations using sample prompt data. The command picker and skill
manager show captures of the real menus in isolated environments. These images
do not depict a personal workstation. The window chrome belongs to the upstream
image renderer.

Prompt themes are customized from [Oh My Posh](https://github.com/JanDeDobbeleer/oh-my-posh).
The upstream [notice](linux-setup/NOTICE.md) and
[MIT license](linux-setup/oh-my-posh-LICENSE.txt) are retained alongside the images.
