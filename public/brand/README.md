# AndHub website brand assets

Source: https://github.com/1hubengineering/branding-guideline (main, 2 November 2026).

The four SVG exports are copied verbatim from:

- `assets/logos/svg/compact/andhub-compact-flat-light.svg`
- `assets/logos/svg/compact/andhub-compact-flat-dark.svg`
- `assets/logos/svg/symbol/andhub-symbol-gradient-light.svg`
- `assets/logos/svg/symbol/andhub-symbol-gradient-dark.svg`

`public/favicon.svg` uses `assets/icons/app-and-avatar/navy/andhub-app-icon.svg` from the same source. The supplied navy app tile uses flat geometry rather than the detailed gradient symbol at favicon sizes.

Keep proportions, internal spaces, and color order intact. Use compact artwork at a minimum 180 CSS pixels wide. Choose artwork for its surrounding surface. Do not add glows, shadows, bevels, or rotation to the artwork.

Company copy, contact details, and leadership come from the source repository's `assets/brand.json`; visual roles follow `assets/ai/brand-context.json` and `assets/documents/AndHub_Brand_Tokens_v1.css`. The source describes the artwork as reconstructed and the standards as proposed. Retain that provenance when distributing the files.
